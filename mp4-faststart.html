✨ 核心功能

专为优化 MP4 网络播放体验而设计

⚡ 秒级起播

将 MP4 的 moov 原子（索引信息）移动到文件开头，浏览器无需等待整个文件下载即可开始播放。

🔧 简单易用

图形界面一键操作，支持批量处理文件夹，无需命令行，轻松集成到工作流中。

🛡️ 安全无损

仅调整文件结构，不重新编码视频内容，100% 保持原始画质与音质。

📦 内置 FFmpeg

集成 FFmpeg 核心能力，兼容性强，支持绝大多数 MP4 编码格式。

🌐 Web 友好

优化后的视频完美适配 HTML5 <video> 标签，提升网站加载性能与 SEO。

🎓 学习项目

由学生开发者开源，代码简洁清晰，是学习视频封装格式的优秀参考。

🚀 快速开始

3 步完成视频优化，立即提升播放体验

💻 下载并运行（Windows）

从 GitHub Releases 页面下载 Windows 专用版本，双击即可运行，无需安装额外依赖

📁 选择目标文件夹

在软件界面中点击「浏览」按钮，选择包含待优化 MP4 视频的文件夹

✨ 自动批量优化

点击「开始优化」，软件将自动处理文件夹内所有 MP4 视频，原地完成索引重排
